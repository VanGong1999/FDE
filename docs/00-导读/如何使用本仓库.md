# 如何使用本仓库

本仓库是 **FDE（Forward Deployed Engineer，AI 前线部署工程师）** 的中文知识库。目标不是「读完很多概念」，而是：**学完核心模块后能交付、能面试、能上手工作**。

## 1. 先选读者路径

| 画像 | 路径 | 预计投入 |
|------|------|----------|
| 有后端/全栈经验，准备转 FDE 或面试 | [学习路径-转岗者](./学习路径-转岗者.md) | 4–8 周（每天 1–2 小时） |
| 编程较弱，想先建立全局图 | [学习路径-零基础](./学习路径-零基础.md) | 先 2–4 周补课，再并入转岗路径 |
| 两周后面试 | [面试通关](../04-面试通关/面试全景与公司对照.md) + [备面计划](../04-面试通关/4-6周备面计划.md) + [09 面试题](../09-面试题/README.md) | 高强度 2–4 周 |
| 已入职 | [交付方法论](../02-交付方法论/Discover-Design-Deploy-Review.md) + [工具箱](../08-工具箱与清单/) | 按项目节奏查阅 |

不确定自己是否适合 FDE？先做 [适合谁不适合谁](../01-角色认知/适合谁不适合谁.md) 自评。

## 2. 推荐阅读顺序（Phase 1 核心）

```text
00 导读（本文 + 术语表）
  → 01 角色认知（知道自己要成为什么）
  → 02 交付方法论（知道现场怎么干活）
  → 03 AI 落地（知道方案怎么选、怎么上线）
  → 04 面试通关（把能力翻译成面试表现）
  → 08 工具箱（复制模板到真实项目）
```

`05–07` 已在 Phase 2 补齐：能力深水区、行业案例、外文精读（含 [FDEInterviews 公开站点地图](../07-外文精读/10-FDEInterviews公开站点地图.md)）。口述题在 [09 面试题](../09-面试题/README.md)；**171 个概念的系统讲解**在 [10 概念课程](../10-概念课程/README.md)（对照公开课程十条轨道的原创中文课）。建议：**概念课建直觉 → 落地文讲上线 → 面试题练口述**。核心四模块读完后再按弱项进 10，避免一开始迷路。

## 3. 怎么读一篇「核心必读」

每篇建议用 **30–45 分钟**：

1. **扫标题与清单**：先看文内 checklist / 决策树，建立地图
2. **精读步骤与示例**：尤其是对话示例、失败模式
3. **动手一次**：把文末动作做完（写一页发现纪要、画一张架构、练一道 Decomposition）
4. **记来源**：外文观点以「参考与来源」为准，需要细节时点开原文

## 4. 文档约定

- **中文为主**；专有名词保留英文（FDE、RAG、Eval、Decomposition）
- **文末「参考与来源」**：链接、用法（综述 / 精读要点）
- **模板**：说明在 `08-工具箱`，可复制正文在 `docs/templates/`
- **术语**：一律以 [术语表](./术语表.md) 为准

## 5. 学习产出物（建议你建立自己的文件夹）

学完 Phase 1，你的私人笔记里最好有：

| 产出物 | 来源章节 |
|--------|----------|
| 转岗自评 + 目标公司短名单 | 01 |
| 一份虚构客户的 Discover 纪要 | 02 |
| 一张 RAG/Agent 决策与简图 | 03 |
| 5 个 STAR 故事 + 3 道 Decomposition 录音 | 04 |
| 填过一遍的 POC 验收表 / Go-Live 清单 | 08 |

有这些产出物，比「收藏了很多链接」更接近可工作状态。

## 6. Phase 与更新

| 阶段 | 你现在能用到的 |
|------|----------------|
| Phase 1 | 骨架 + 角色 / 方法论 / AI 落地 / 面试 + 工具模板 |
| Phase 2（已完成） | 行业案例 ×6、外文精读 ×7、能力深水区（数据栈/SSO/网络/变更/产品化） |

贡献方式见根目录 [CONTRIBUTING.md](../../CONTRIBUTING.md)。

## 7. 站点与本地预览

- 在线：以仓库 README / GitHub Pages 地址为准  
- 本地：按根目录说明用 Docsify 打开 `index.html`  
- 侧栏：`_sidebar.md`；找不到文时先搜文件名再搜标题

## 8. 常见用法误区

| 误区 | 纠正 |
|------|------|
| 按目录从 00 读到 08 不产出 | 每章至少完成一个文末动作 |
| 只收藏外文精读 | 精读要落到案例口述或护栏清单 |
| 模板空白复制不填 | 用虚构客户填一遍，比空模板有用 |
| 跳过 02 直接刷面试 | 没有交付语言，行为面会空 |
