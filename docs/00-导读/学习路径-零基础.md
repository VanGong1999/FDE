# 学习路径：零基础 / 编程较弱

面向：**对 FDE 感兴趣，但编程或工程经验较弱**的读者。目标不是让你立刻面 Palantir，而是用最短路径补到「能跟上主路径 Week 2」。

> 主路径仍以 [学习路径-转岗者](./学习路径-转岗者.md) 为准。本页是**前置合流地图**。

---

## 你需要先建立的三块能力

| 块 | 最低标准（能做什么） | 建议时长 |
|----|----------------------|----------|
| 编程基础 | 读懂 Python 函数/类；写小脚本调 HTTP API；会用 Git | 2–4 周 |
| Web/后端直觉 | 知道 API、鉴权、数据库、日志是什么；能画简单请求链路 | 1–2 周 |
| LLM 使用直觉 | 会用主流 Chat/API；理解 token、上下文、幻觉、工具调用概念 | 1 周 |

详细清单见 [零基础编程补课地图](../05-能力补强/零基础编程补课地图.md)。

---

## 阶段 1 — 补课（2–4 周）

按 [零基础编程补课地图](../05-能力补强/零基础编程补课地图.md) 执行。每周验收：

| 周 | 验收题 |
|----|--------|
| 1 | 本地跑通一个调用 LLM API 的脚本，打印回复 |
| 2 | 用 Git 管理该脚本；写 README 说明如何运行 |
| 3 | 读一个开源小项目的 README + 入口文件，口述「请求从哪进、从哪出」 |
| 4 | 做一个「本地文件夹问答」最小 Demo（甚至先用官方 Playground + 手工粘贴也行，但要写清局限） |

---

## 阶段 2 — 并入主路径

当满足下列条件，切换到 [学习路径-转岗者](./学习路径-转岗者.md) 的 **Week 2**：

- [ ] 能独立写脚本调 API，并处理错误与密钥（环境变量）
- [ ] 理解 REST、JSON、基本 SQL SELECT
- [ ] 能向他人讲清 RAG 在做什么（检索 → 增强 → 生成）

角色认知（Week 1）可快速复习后跳过细节。

面试（Week 4）建议等你有一个**可演示小项目**再全力投入；否则先把项目做扎实。

---

## 不要做的事

- 不要一上来刷大量算法题（FDE 更看重应用与拆解；算法按目标公司再补）
- 不要同时学 5 个 Agent 框架；先会「HTTP + 提示词 + 检索」
- 不要用「收藏 100 篇博客」代替「一个能跑的 Demo」
