# 学习路径：转岗者（主路径）

面向：**已有后端或全栈经验**，希望转入 FDE / FDSE / Applied AI Engineer，或在现有公司做「客户侧 AI 交付」。

总时长建议 **4–8 周**。每周 7–12 小时即可；若在高强度备面，可压缩为 4 周。

---

## 开始前：30 分钟定位

1. 读 [什么是 FDE](../01-角色认知/什么是FDE.md)
2. 做 [适合谁不适合谁](../01-角色认知/适合谁不适合谁.md) 自评
3. 浏览 [公司图谱与岗位差异](../01-角色认知/公司图谱与岗位差异.md)，选出 2–3 家目标类型（产品型 AI 公司 / 平台型 / 咨询交付型 / 国内大厂应用 AI）

输出：一页「目标角色 + 目标公司类型 + 我的缺口三条」。

## Week 5–8（加长版：打磨与项目）

若时间充裕，不要急着海投：

1. **做一个可演示项目**：带 eval、权限说明、成本/延迟备注、rollout 计划（对齐 OpenAI 类 take-home 评分维度）
2. **补能力短板**：优先 [SSO 与权限](../05-能力补强/企业SSO与权限模型.md)；需要时再读 [Snowflake/Databricks](../05-能力补强/Snowflake与Databricks现场.md)、[变更管理](../05-能力补强/变更管理与培训设计.md)
3. **读外文精读**：先 [Decomposition](../07-外文精读/02-Decomposition面试框架与操练.md) + 目标公司篇（[Palantir](../07-外文精读/03-Palantir-FDSE面试指南.md) / [OpenAI](../07-外文精读/04-OpenAI-FDE面试指南.md) / [Anthropic](../07-外文精读/05-Anthropic-Applied-AI面试侧重点.md)）；地图用 [Exponent](../07-外文精读/01-Exponent-FDE面试2026指南.md)
4. **精读 2 个行业案例并口述 Decomposition**：从 [06 案例目录](../06-行业案例/README.md) 选与目标岗位相近者；可用 [_案例模板](../06-行业案例/_案例模板.md) 写自己的复盘
