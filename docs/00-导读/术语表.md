# 术语表

本表为仓库统一用语。首次出现在正文时建议「中文（英文）」；之后可直接用英文缩写。

## 角色与组织

| 术语 | 含义 |
|------|------|
| **FDE** | Forward Deployed Engineer，前线部署工程师。深入客户环境，把产品/模型能力做成可运行的业务方案并推动上线。 |
| **FDSE** | Forward Deployed Software Engineer，常见于 Palantir 等公司的称谓，偏软件工程深度。 |
| **Applied AI Engineer** | 应用 AI 工程师；Anthropic 等公司相近岗位，强调安全、评测与可靠部署。 |
| **SWE** | Software Engineer，产品研发工程师，通常不长期驻场客户。 |
| **SE** | Solutions Engineer / Sales Engineer，售前解决方案，偏赢单与 PoC 演示。 |
| **SA** | Solutions Architect，解决方案架构师，偏架构与集成设计。 |
| **PM** | Product Manager，产品经理。 |
| **Stakeholder** | 干系人：出资方、业务用户、IT、安全、法务等。 |
| **Champion** | 客户内部推动项目的关键支持者。 |

## 交付与方法论

| 术语 | 含义 |
|------|------|
| **Discover** | 发现：弄清谁痛、被什么指标衡量、约束与数据现实。 |
| **Design** | 设计：范围、架构、成功标准、风险与试点计划。 |
| **Deploy** | 部署：实现、集成、权限、上线与培训。 |
| **Review** | 复盘：效果、学习反馈产品、模式化复用。 |
| **POC / PoC** | Proof of Concept，概念验证，证明「技术上可行」。 |
| **Pilot** | 试点：在真实用户/真实数据上小范围验证「业务上有用」。 |
| **MVP** | Minimum Viable Product，最小可用产品。 |
| **Decomposition** | 问题拆解（亦为面试轮次名）：先用户与结果，再子问题与硬点。 |
| **Rollout** | 分阶段推广上线计划。 |
| **Runbook** | 运维/应急操作手册。 |
| **Handoff** | 向客户 IT 或内部产品团队交接。 |

## AI / LLM 技术

| 术语 | 含义 |
|------|------|
| **LLM** | Large Language Model，大语言模型。 |
| **Prompt** | 提示词；含系统提示、用户提示、工具说明等。 |
| **Token** | 模型计费与上下文的基本单位。 |
| **Context window** | 上下文窗口，单次可塞入的信息上限。 |
| **Hallucination** | 幻觉：模型生成看似合理但不实的内容。 |
| **RAG** | Retrieval-Augmented Generation，检索增强生成。 |
| **Embedding** | 嵌入向量，用于语义检索。 |
| **Chunking** | 文档切片策略。 |
| **Rerank** | 重排序，提升检索精度。 |
| **Agent** | 能规划并调用工具完成多步任务的系统。 |
| **Tool calling / Function calling** | 模型发起结构化工具调用。 |
| **MCP** | Model Context Protocol，模型与工具/数据源连接的一种开放协议生态。 |
| **Fine-tuning** | 微调：用领域数据更新模型权重（成本与责任更高）。 |
| **Eval** | Evaluation，评测：用数据集与量规衡量系统好坏。 |
| **Golden set** | 黄金集：高质量标注的评测样本集。 |
| **Rubric** | 评分量规：人工或自动打分的标准。 |
| **Guardrails** | 护栏：输入输出过滤、策略、权限与安全约束。 |
| **HITL** | Human-in-the-loop，人机回环。 |
| **Grounding** | 回答锚定在检索到的证据上。 |
| **Latency / Cost** | 延迟与成本，生产关键约束。 |

## 数据与安全

| 术语 | 含义 |
|------|------|
| **PII** | Personally Identifiable Information，个人身份信息。 |
| **RBAC / ABAC** | 基于角色 / 基于属性的访问控制。 |
| **SSO** | Single Sign-On，单点登录。 |
| **Data residency** | 数据驻留：数据必须留在某地域/某环境。 |
| **VPC / Private link** | 私有网络接入，常见企业要求。 |
| **Audit log** | 审计日志。 |

## 面试相关

| 术语 | 含义 |
|------|------|
| **Recruiter screen** | 招聘初筛。 |
| **Technical screen** | 技术初筛（线上编码或电话）。 |
| **Onsite / Loop** | 现场或连续多轮面试。 |
| **Take-home** | 带回家的作业项目。 |
| **Learning round** | 学习轮：在规定时间内理解并扩展陌生代码库。 |
| **Re-engineering** | 重构/再工程轮：改进已有实现。 |
| **STAR** | Situation-Task-Action-Result，行为面叙事结构。 |
| **Hiring manager** | 招聘经理轮。 |
| **C.A.S.E.** | Clarify → Architect → Solve(Delta) → Evaluate，案例面试四步。 |

## Awesome FDE / 战略与合规补充

| 术语 | 含义 |
|------|------|
| **The Delta** | 产品开箱能力与客户使命成功之间的工程缺口（Palantir 语境常用）。 |
| **Productized Consulting** | 用最终可回流核心产品的代码解决客户独特问题。 |
| **Embedded Engineering** | 持有客户凭证、进客户协作频道、直接向客户生产交付。 |
| **Last-Mile Integration** | 把现代 SaaS/AI 接到遗留、文档不全的企业系统。 |
| **Air-Gap / Tactical Edge** | 零或断续网络环境；需本地仓库与离线权重。 |
| **VPC SC** | VPC Service Controls，防数据外泄的云服务周边边界。 |
| **Hardening** | 从「本机可跑」到满足 SOC2/HIPAA 等的加固。 |
| **Shadow IT** | 未经批准却常藏「最干净有用数据」的工具/库。 |
| **System of Record (SoR)** | 某类信息的权威数据源。 |
| **ADK** | Agent Development Kit，Google 开源多 Agent 框架。 |
| **A2A** | Agent2Agent 协议，Agent 间发现与协作。 |
| **Grounding** | 将 LLM 接到真值数据（RAG/搜索）以可引用。 |
| **Pairwise Evaluation** | 裁判模型比较两路输出并给理由（原 AutoSxS 思路演进）。 |
| **Faithfulness** | 答案仅源自检索上下文的程度（幻觉反向分）。 |
| **SOW / MSA** | 工作说明书 / 主服务协议。 |
| **Cost of Inaction** | 不部署每天损失的量化论证。 |
| **UAT** | 用户验收测试。 |
| **Day 2 Operations** | FDE 离开后的监控、再训练与 Run Team。 |
| **ATO / STIG / CMMC / FedRAMP** | 政府与国防认证/加固相关缩写，见气隙专篇。 |
| **MECE / BLUF** | 互斥穷尽；结论先行。 |
| **Medallion** | Bronze/Silver/Gold 数据分层。 |
