# 编码与 Learning 轮

FDE 编码考察偏 **实用、沟通、在约束下交付**，Learning 轮则模拟日常：「一小时内在陌生代码里变得有用」。本篇给转岗者复习重点，**不是**题海。

---

## 1. 编码轮：考什么

综合公开画像（尤其 Palantir 类）：

| 常见元素 | 备面含义 |
|----------|----------|
| 图与网格（BFS、拓扑等） | 复习基础图算法到能手写 |
| 多部分递进题 | 先做出正确版本，再扩展 |
| 小数据集汇总 | 清晰的数据模型与边角 |
| SQL | Join、聚合、窗口基础 |
| 语言灵活 | 选你最熟的；Python 常见 |

### 沟通清单（边写边说）

1. 复述题目与例子  
2. 说出暴力解与目标复杂度  
3. 先写对，再优化  
4. 想测试用例（空、一、环、重复）  
5. 主动处理错误输入策略  

### 转岗两周编码计划

| 日 | 焦点 |
|----|------|
| 1–3 | 数组/哈希/双指针热身 |
| 4–6 | BFS/DFS/拓扑 |
| 7–8 | 堆、并查集（按需） |
| 9–10 | SQL 50 题级练习 |
| 11–14 | 限时模拟 + 复盘沟通 |

若目标是强应用 AI 公司、弱算法，把一半时间改去 **Take-home 项目**。

## 2. Learning 轮：流程

典型设定：给你一个文档不全的小库/API，要求理解并**扩展功能且不破坏旧行为**。

### 推荐 60 分钟分配

| 分钟 | 动作 |
|------|------|
| 0–10 | 跑起来；跑测试；读 README/入口 |
| 10–25 | 画模块图；找扩展点；写假设 |
| 25–50 | 实现最小改动；补测试 |
| 50–60 | 整理说明：你改了什么、风险、下一步 |

### 高分行为

- 先让测试绿，再加功能  
- 模仿现有风格，不引入巨型重构  
- 大声说「我现在在验证 X」  
- 写清未完成项  

### 低分行为

- 盲目大重构  
- 不问如何运行就改  
- 无测试  
- 沉默过久

## 3. 自制 Learning 练习

1. 找一个你不熟的中小型开源工具（CLI 或小 Web）  
2. 计时 60 分钟：加一个小功能 + 测试  
3. 复盘：定位时间花在哪  

每周 1–2 次，比只刷题更贴 FDE。

---

## 4. SQL 速查（面试够用）

务必熟练：

- `JOIN` / `LEFT JOIN` 与空值陷阱  
- `GROUP BY` + `HAVING`  
- 窗口函数：`ROW_NUMBER`, `SUM() OVER()`  
- 去重与「每个用户最新一条」  

结合业务口述：「如何找连续登录」「漏斗转化」。

---

## 5. AI 相关现场编码（部分公司）

可能出现：

- 解析模型 JSON 输出并校验  
- 简单检索评分函数  
- 对日志做聚合找失败模式  

重点是工程洁癖与边界，不是训练理论。
