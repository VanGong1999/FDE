# Decomposition 拆解面

**Decomposition** 是 FDE 面试的标志性轮次：面试官给出模糊、常被「伪造成解决方案」的业务诉求，考察你能否在压力下结构化拆解。现场工作每天都在做同一肌肉。

本篇对齐公开的五步评分思路（见 The Forward Deployed Decomposition），并给出中文练习法。

---

## 1. 五步框架（务必内化）

| 步 | 动作 | 合格样子 |
|----|------|----------|
| 1 | **用户与结果** | 先说清为谁、被什么指标衡量；不先谈 App/Chatbot |
| 2 | **假设与范围** | 大声假设，并向面试官确认；划出非目标 |
| 3 | **拆子问题** | 3–5 个**问题部件**（不是「调研→开发→上线」阶段） |
| 4 | **硬点** | 指出做错会让结果崩掉的那块，并辩护为何硬 |
| 5 | **具体下一步** | 可执行、可证伪；说明如何知道自己错了 |

### 扣分最快的行为

- 第一分钟就开聊技术栈或产品形态  
- 长时间「架构」却无任何具体物  
- 子问题写成项目管理阶段  
- 硬点说成「需要微服务」这类空话  
- 等面试官问才说如何验证

## 2. 开场 60 秒脚本

```text
我想先确认用户和成功标准，再拆问题。
我假设……（假设）——这样合理吗？
在此基础上，我会避免……（非目标）。
关键子问题是：1… 2… 3…
其中最硬的是……因为……
我下一步会……；若看到……说明假设错了。
```

练到不看稿。

## 3. 面试官打断时怎么办

公开练习建议里常见的打断类型：

| 打断 | 你的反应 |
|------|----------|
| 「这是给谁的？他们被什么衡量？」 | 立刻补用户与指标，不要辩护自己刚才的功能 |
| 「说了太多结构，给点具体的」 | 给一个例子用户故事或一个本周动作 |
| 「哪里最难？」 | 直接答硬点 + 为何 + 第一刀 |
| 「继续说，我只能评你说出口的」 | 不要沉默；边想边结构化输出 |

## 4. 练习题库（先自己答，再对照提示）

对每题限时 **8–10 分钟口述**，录音，用文末评分表自检。

1. 「给我们做一个员工 ChatGPT。」  
2. 「用 AI 做智能客服，下周要上。」  
3. 「把所有合同自动审核掉。」  
4. 「做一个销售预测仪表盘。」（伪造成解决方案）  
5. 「我们希望提高 NPS。」  
6. 「内部知识太分散，做个搜索。」  
7. 「仓库拣货经常错，上个视觉 AI。」  
8. 「帮政府做一个反欺诈平台。」  
9. 「把 Excel 流程都 Agent 化。」  
10. 「老板要生成式 BI，人人用自然语言查数。」  

**提示方向（节选）**

1. 用户可能是新员工；硬点常是权限与过期知识；下一步：单部门报销类问答试点。  
2. 指标是首响还是一次解决？硬点：工单写回与幻觉对外；下一步：坐席助手影子模式。  
3. 「自动审核」要拆成条款类型；硬点：标签与责任；下一步：一类高风险条款 + HITL。  
4. 先问谁的决策、预测周期；或许不需要 AI。  
5. NPS 是结果指标；拆驱动因素；硬点是归因。  
10. 硬点常是语义到 SQL 的正确性与权限；下一步：限定主题域 + 强制解释与审批。

## 5. 完整示范（缩写版）

**题**：「做一个能回答全公司问题的机器人。」

**答（结构）**：

1. **用户/结果**：假设主要用户是门店运营，成功是「政策类问题自助解决率」与「升级专家次数下降」；请确认是否还有法务强制场景。  
2. **假设/范围**：先假设不做开放域闲聊、不做自动改系统；知识以零售运营手册为主。  
3. **子问题**：①政策真相源与版本；②门店角色权限；③哪些问题必须升级人工；④如何度量自助成功；⑤过期内容治理。  
4. **硬点**：权限 + 版本——答错政策有合规成本；没有 ACL 的检索不能上。  
5. **下一步**：选 1 个区域 20 家门店、手册子集，建 80 条黄金集（含应拒答），两周测「建议被采纳/解决」；若权限模型无法落地则停生成、只做权限内搜索。

## 6. 评分表（PASS/FAIL）

每题自检，引用你录音里的**具体句子**：

| 标准 | P/F | 证据句 |
|------|-----|--------|
| 在谈功能前说出用户与结果 | | |
| 大声假设并确认范围 | | |
| 3–5 个问题部件（非阶段） | | |
| 硬点真实且有辩护 | | |
| 具体下一步 + 如何知错 | | |

公开练习观点：初练常挂至少两项——**评分要狠**。

---

## 7. 训练计划

| 天 | 动作 |
|----|------|
| 每天 | 1 题口述 + 自评 |
| 每三天 | 找朋友按「打断脚本」扮演面试官 |
| 每周 | 复盘错题本：你最常缺哪一步 |

可用 AI 扮演面试官，但要求它严格按五步打分（见来源站点的 drill 思路）。
