# 反模式与踩坑

收集 FDE / 企业 AI 交付中的高频失败模式。建议打印「症状 → 根因 → 纠正」表，挂在项目周报旁。

---

## 1. 问题定义类

| 反模式 | 症状 | 纠正 |
|--------|------|------|
| 方案先行 | 一上来选模型/框架 | 先写问题陈述与指标 |
| 万能机器人 | 开放域什么都答 | 收窄任务与知识边界 |
| 指标漂移 | 每周重新定义成功 | 冻结试点指标 |
| 只听管理层 | 一线不用 | 强制一线访谈与旁听 |
| 忽视非目标 | 范围无限 | 书面非目标 |

---

## 2. 技术与 AI 类

| 反模式 | 症状 | 纠正 |
|--------|------|------|
| Demo 驱动开发 | 只优化演示路径 | Eval 集含困难例与安全例 |
| 无检索的「知识库」 | 幻觉当事实 | RAG + 强制引用 + 拒答 |
| Agent 无限工具 | 越权、不可控 | 最小权限、HITL、允许列表 |
| 忽略成本 | 账单爆炸 | 预算、缓存、模型分级 |
| 微调崇拜 | 未试 prompt/RAG 就训 | 走决策树 |
| 日志裸奔 | PII 进第三方 | 脱敏、保留策略、私有部署评估 |
| 单次提示拼真相 | 复杂流程靠玄学 | 工作流拆分 + 校验器 |

详见 [03-AI落地](../03-AI落地/企业AI落地全景.md)。

## 5. 案例分析（合成）

### 案例 A：全自动客服三周翻车

- **经过**：管理层看了竞品 Demo，要求三周全自动。团队上线后出现错误退款建议。
- **根因**：无门禁、无 HITL、无 eval、范围=全量。
- **纠正**：回退到坐席助手；建立黄金集；错误升级人工；重新谈对外口径。

### 案例 B：知识库「准确率 90%」无法复现

- **经过**：汇报准确率来自 10 个精选问题。
- **根因**：无固定测试集；训练/测试污染。
- **纠正**：冻结 100 条分层抽样集；分类型报表；展示失败案例。

### 案例 C：权限用超级账号

- **经过**：Pilot 很快，生产卡在安全审计。
- **根因**：文档级 ACL 未设计。
- **纠正**：检索层注入用户身份过滤；补审计；延期但可过审。

## 6. 个人防坑清单（每周五）

- [ ] 本周是否更新了风险而不仅是进度？
- [ ] Eval 是否因改动而回归？

- [ ] 是否有只有我知道的关键步骤？
- [ ] 成本与延迟是否看过？
