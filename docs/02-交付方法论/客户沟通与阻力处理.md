# 客户沟通与阻力处理

FDE 的杠杆很大一部分在**沟通质量**：同样的技术现实，可以说成「不行」，也可以说成「有三条路径，推荐这条，因为…」。本篇给可直接彩排的结构与话术。

---

## 1. 沟通层级与频率

| 对象 | 你提供什么 | 频率建议 |
|------|------------|----------|
| 一线用户 | 倾听、可用性、快速修复 | 试点期高密度 |
| Champion | 进展、障碍、需要其推动的事项 | 每周 |
| Sponsor | 决策选项、风险、指标 | 双周或里程碑 |
| IT/安全 | 精确数据流、权限、变更窗口 | 按需 + 早沟通 |
| 内部产品 | 现场模式与需求 | 定期同步 |

模板：[周报模板](../08-工具箱与清单/周报模板.md)

## 2. 决策备忘录（一页纸）

当出现分歧，不要只靠会议记忆：

```text
标题：
背景（3–5 行）：
需要决策的问题：
选项 A/B/C（每个：描述、利弊、成本/风险、时间）：
推荐：
需要谁在何时拍板：
若未决策的默认后果：
```

这在面试行为面里也是高分素材（「我如何推动决策」）。

## 3. 礼貌而坚定地推回

### 原则

- 推回的是**范围/方式**，不是人
- 先对齐目标，再谈约束
- 永远给替代路径（哪怕是「分阶段」）
- 把决定权交回有权的人，并记录

### 话术骨架

1. **复述目标**：「我们都希望降低初审时长。」
2. **约束现实**：「当前合同不能出域，且没有标注集。」
3. **若硬上会发生什么**：「两周全自动上线会导致无法审计的误判风险。」
4. **选项**：「A 影子助手 4 周；B 外包标注后自动；C 缩小到 NDA 条款类。」
5. **推荐 + 请求拍板**。

### 示例

> 「可以做全自动回复，但我不能在没有评测与升级路径时推荐。若必须对外承诺日期，我建议承诺『坐席助手试点』而不是『无人客服』，否则风险是品牌与合规事件。您希望选哪条对外口径？我可以帮写一版。」

## 4. Demo vs 生产：管理预期

| Demo 可以说 | 必须同时说 |
|-------------|------------|
| 技术路径演示 | 所用数据范围 |
| 乐观路径耗时 | 依赖（权限、标注、IT） |
| 潜在价值 | 尚未验证的假设 |

**禁止**：用精心挑选的 3 个问题代表整体准确率。

演示结构建议：场景 → 真实约束 → 现场操作 → 失败例子 → 下一步门禁。

## 5. 处理典型阻力

| 阻力 | 可能原因 | 策略 |
|------|----------|------|
| 「先做出来再看指标」 | 逃避问责 | 坚持门禁；缩小到可测切片 |
| IT 拖延 | 风险/带宽 | 给最小开通清单；升级 sponsor |
| 用户不用 | 工作流不匹配 | 现场观察；嵌入现有工具 |
| 安全一刀切否定 | 信息不对称 | 提供架构图、数据分级、对标案例 |
| 范围暴涨 | 成功焦虑 | 时间盒 + 非目标清单 |
| 内部抢功/甩锅 | 组织政治 | 书面角色 RACI；对事不对人 |

## 6. 周会怎么开（30 分钟）

1. 指标（5 min）  
2. 完成与风险（10 min）  
3. 需要决策（10 min）  
4. 下周焦点（5 min）  

没有决策的会，改成异步周报。

---

## 7. 远程与驻场

- 驻场：多安排「旁听真实工作」而非多开会
- 远程：提高书面密度；录短视频演示
- 时区：约定「决策窗口」避免阻塞过夜

---

## 8. 彩排题（对着同事练）

1. Sponsor 要求下周全员开放自动发送邮件  
2. 安全拒绝一切外部 LLM，业务又要求生成能力  
3. Champion 休假，项目失去推动力  
4. 销售在客户前承诺了你未同意的功能  

为每题写 5 行决策备忘录。
