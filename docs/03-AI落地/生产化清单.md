# 生产化清单

把试点变成可运营系统时，用本清单做 Go/No-Go。可与 [生产 Go-Live 清单](../08-工具箱与清单/生产Go-Live清单.md) 对照使用。

---

## 1. 可靠性

- [ ] 超时、重试、降级路径明确（如：仅检索摘要 / 转人工）  
- [ ] 幂等与去重（Webhook、工具写操作）  
- [ ] 依赖健康检查（模型 API、向量库、内部 API）  
- [ ] 限流与配额（按租户/用户）  
- [ ] 回滚方案（配置、提示词、索引版本可回退）  

---

## 2. 观测与运营

- [ ] 结构化日志（request_id、user、工具轨迹摘要）  
- [ ] 追踪（关键跨服务调用）  
- [ ] 指标看板：延迟、成本、错误、采纳率  
- [ ] 告警与值班人  
- [ ] Runbook：常见故障 5 条以上  
- [ ] 反馈入口（点踩、上报）进入 backlog  

---

## 3. 安全与合规

- [ ] SSO/身份集成完成  
- [ ] 文档/行级权限在检索与工具层强制执行  
- [ ] 密钥管理（KMS/密管），无硬编码  
- [ ] PII 处理：脱敏、保留期、访问控制  
- [ ] 数据驻留与出站路径符合合同  
- [ ] 审计日志：谁问了什么、调了何工具、谁批准  
- [ ] 提示注入与越权用例子做过测试  
- [ ] 供应商（模型商）条款已审  

---

## 4. 成本与延迟

- [ ] 单次请求成本估算与预算告警  
- [ ] 模型分级（简单查询走小模型/缓存）  
- [ ] 检索 top-k 与上下文长度有上限  
- [ ] 缓存策略（安全前提下）  
- [ ] SLA：P95 延迟目标已测  

---

## 5. 变更管理

- [ ] 提示词/编排版本化  
- [ ] 索引重建流程文档化  
- [ ] 配置变更需评审（尤其高危工具开关）  
- [ ] Eval 回归是合并门槛  

---

## 6. 用户与交接

- [ ] 培训完成，录屏可查  
- [ ] 客户侧产品/技术 owner 指名  
- [ ] 支持渠道与升级路径  
- [ ] 已知限制对用户可见（诚实 UX）  

---

## 7. Go/No-Go 会议议程（45 分钟）

1. 指标相对基线（10）  
2. 开放风险与安全结论（10）  
3. 运营就绪（10）  
4. 决策：上线 / 有条件上线 / 延期（10）  
5. 沟通口径（5）  

输出必须是书面决策，不是「大家觉得可以」。

---

## 8. 上线后 14 天

- 每日失败案例回顾  
- 成本曲线  
- 用户访谈 5 人  
- 决定是否扩大范围  

然后进入 [Review](../02-交付方法论/Discover-Design-Deploy-Review.md)。

## 参考与来源

本文为原创生产清单；安全项对齐 OWASP LLM 风险意识（S23）与公开 FDE「production-shaped」要求（S03）。
