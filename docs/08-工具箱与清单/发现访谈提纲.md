# 发现访谈提纲

配合 [需求发现与问题拆解](../02-交付方法论/需求发现与问题拆解.md)。访谈后把答案写入 [templates/发现访谈纪要.md](../templates/发现访谈纪要.md)。

## 会前

- [ ] 明确受访者角色（用户/赞助人/IT/安全）  
- [ ] 征求是否可旁看真实系统/工单（脱敏）  
- [ ] 准备「我不是来推销功能，是来理解工作」的开场  

## 访谈问题（按需取舍）

### 工作流

1. 请带我走一遍最近一次真实处理过程。  
2. 哪些步骤最耗时？哪些最易错？  
3. 用到哪些系统？哪里要来回复制？  

### 成功标准

4. 你的上级用什么数字看这个团队？  
5. 若只能改善一件事，选哪件？  
6. 怎样算试点成功？怎样算失败该停？  

### 风险与约束

7. 最近一次严重失误的后果是什么？  
8. 数据能否出内网？有哪些合规要求？  
9. 谁有权否决上线？  

### 组织

10. 谁会日用？谁只是「听说要 AI」？  
11. 过去类似工具为什么失败？  
12. 培训与变更窗口有什么限制？  

## 会后 24 小时内

- [ ] 发出纪要请对方确认问题陈述  
- [ ] 列出开放问题与下一步时间盒  
- [ ] 更新风险登记
