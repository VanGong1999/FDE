# 生产 Go-Live 清单

用于 Pilot → Production。填写版：[templates/Go-Live检查表.md](../templates/Go-Live检查表.md)。详细项见 [生产化清单](../03-AI落地/生产化清单.md)。

## 摘要门禁

### 可靠性与运营

- [ ] 降级与回滚演练过  
- [ ] 看板与告警指向值班人  
- [ ] Runbook 已交客户  

### 安全

- [ ] SSO/ACL 强制验证通过  
- [ ] 密钥与 PII 策略就绪  
- [ ] 审计日志可查  

### 质量

- [ ] Eval 回归通过线  
- [ ] 已知限制对用户可见  

### 采用

- [ ] 培训完成  
- [ ] 支持渠道明确  

### 决策

- [ ] Go / 有条件 Go / No-Go 书面记录
