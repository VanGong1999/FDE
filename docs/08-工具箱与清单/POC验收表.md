|----|----|----------|------|
| P1 | 问题陈述确认 | 赞助人签字/邮件确认 | |
| P2 | 目标环境路径 | 非仅笔记本；网络/驻留可行 | |

| P6 | 风险与缓解 | Top3 有负责人 | |
| P7 | Owner | 客户侧对接人指名 | |
