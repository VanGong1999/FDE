# Day 1 · 环境搭建（VS Code / Git / Node / uv）

一句话总结：装齐四件套——VS Code、Git、Node、uv，为本周后续开发做好准备。

## 要装的四样东西

| 工具 | 是什么 | 备注 |
|------|--------|------|
| **VS Code** | 代码编辑器 | 也可用 Cursor 或其他 IDE |
| **Git** | 版本控制 | 约 80% 人已装 |
| **Node** | 服务端 JS 运行时 | 建议 v26 或更高 |
| **uv** | Python 包管理器（Astral 出品） | **现已被 OpenAI 收购** |

> 四样都装不上，可能意味着该先修前置课程。

## 通用操作（VS Code 内终端）

- 打开终端：`Ctrl+Shift+反引号`（反引号在键盘左上角，≠ 撇号）；Mac 也可 `Command+Shift+N` 开新窗口。
- PC 终端即 PowerShell；Mac 终端为 zsh。
- 检查版本：`git --version`、`node --version`、`uv --version`。

## PC（Windows）安装

| 工具 | 命令/方式 |
|------|-----------|
| VS Code | 浏览器打开 `code.visualstudio.com` → Download for Windows → 安装 |
| Git | `winget install --id Git.Git` |
| Node | `winget install OpenJS.NodeJS`（装完 `node --version` 验证，目标 v26+） |
| uv | 访问 `docs.astral.sh` 复制 PowerShell 安装命令执行 |

- 装完一般需**开新终端**，有时需**重启电脑**。

## Mac（macOS）安装

| 工具 | 命令/方式 |
|------|-----------|
| VS Code | `code.visualstudio.com` → Download for macOS → 安装 |
| Git | `git --version`，未装会**自动提示并安装** |
| Node | `brew install node`，或 `nvm install 26`（nvm = Node Version Manager） |
| uv | 访问 `docs.astral.sh`，复制 macOS/Linux 安装命令执行 |

### Node 版本选择
- **v26**：最新版（讲师同款）。
- **v24**：长期支持（LTS）。
- 推荐「防弹」方式：**nvm（Node Version Manager）**，可管理多版本 Node；`nvm install 26` 后无需开新终端。
- 用 Homebrew 则：`brew install node@26`。

## 关键点

- 每次安装后**开新终端**再验证版本，仍不行就重启。
- uv 是「神话般的包管理器」，后续 `uv sync` 会自动构建环境甚至自动装 Python。
