# 课程简介与三周总览

一句话总结：FDE 与 AI 架构师是当前 AI 领域最热门的岗位，本课程用三周时间把学员从 LLM/Agent 实操带到「AI 架构师 + 前沿部署工程师」的行业就绪状态。

## 为什么这门课重要

- **岗位最热**：FDE 与 AI 架构师是「AI 领域最抢手的工作」，需求量同比（year-on-year）增长 **10 倍**。
- **薪资高**：底薪最高可达 **$400,000**；顶级表现者（top performer）**含股权的总薪酬可超过 100 万美元**。
- 讲师自述这是他所有课程里「最重要、最及时（most timely）」的一门。

## 三周课程内容（大纲）

**Week 1 —— 所有与 LLM 和 Agent 相关的内容**，包括：
- ADLC（Agentic Development Life Cycle，代理开发生命周期）
- 开源模型的本地推理（local inference of open source models）
- Harness Engineering（线束工程，含 Claude Agent SDK）

**Week 2 —— 成为 AI 架构师**，包括：
- Observability（可观测性）与 Evals（评测）
- Durable State（持久状态）、Human in the loop（人在回路）
- Agentic RAG、MCP（Model Context Protocol）
- Agent teams / swarms / fleets（代理团队、蜂群、舰队）
- Recursive self-improvement（递归自我改进）

**Week 3 —— 成为 FDE**，包括：
- Solutions architecture（解决方案架构）
- Security guardrails（安全护栏）、Responsible AI（负责任 AI）
- API gateways、Enterprise context layers（企业上下文层）、Integrations（集成）
- 最终收敛到 **Capstone Project（顶点项目）**，是讲师做过最大的项目

## 教学方法论

- 学习目标与真实岗位 JD（Job Description）**强对齐**，可直接用于工作。
- **真正的学习不在讲座里，而在动手构建（building）**：先做 Labs，再做大型商业项目。
- Capstone 是「所有课程里最大的项目」。

## 适合人群与门槛

- **理想对象**：已有一点 LLM 经验的学员（课程的「甜蜜点」）。
- **完全新手**：也能跟，但第一周会很紧张（crash course，速成班）。
- **有经验者**：第一周可 1.5x / 2x 倍速跳过。
- 无严格先修要求；若跟不上可先去修前置课程（见 [03-三周路线图](./03-Day1-三周路线图.md)）。

## 讲师承诺与互动

- 讲师随时可联系（Udemy / 邮件），回复很快。
- 「人们总以为我是 agent，但我不是 agent，是我本人在回。」
- 建议学员：现在就在日历上标记「三周后：恭喜，我现在是一名 FDE」，用于自我督促。
