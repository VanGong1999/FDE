# 为视频库预测观看时长（网飞Netflix风格），该如何搭建这套系统？
观看时长是所有人都在优化的目标指标，但几乎没人能干净准确地衡量它。你只能观测到用户**选择播放**的那些视频的观看分钟数；数据分布极度长尾偏斜；视频展示位置也会影响最终观看时长。这个面试题的核心，是看你能不能诚实地处理一个带有偏差的标签。

### 04 为视频库预测观看时长（网飞Netflix风格），该如何搭建这套系统？
难度：难 | 标签：Netflix、YouTube、Disney+
2条回答，已解锁

一句话核心摘要：拆成两个阶段建模：播放概率 P(play)，以及【在已经播放的条件下的期望观看时长 E[watch time | play]】。观看时长分支只在产生播放行为的数据上训练，同时修正带来这些播放记录的**选择偏差**与**位置偏差**；对长尾严重的标签做变换（log1p变换或者分位数分桶）；最终好坏判断依靠线上A/B实验的互动指标和防护约束指标，**不能只靠线下平均绝对误差MAE**。整套问题的难点在于：标签只存在于用户已经主动选择点开的内容上。

---
## 解题思路
在碰模型之前，先明确业务真正想要的目标：不是原始观看分钟数（原始时长会助长冗长拖沓的内容、自动播放刷时长的套路），而是**价值化观看时长**：做上限截断，还可以结合完播率、满意度调研、下游留存做加权。
之后问自己三个决定方案设计的问题：
1. 每次请求的候选集是什么（数万部影片，而不是整个内容库）
2. 什么算作正标签、统计窗口怎么定（是2分钟采样，还是整集看完）
3. 我们要记录哪些反馈数据（曝光、位置、播放、观看秒数、点赞、中途退出）

理清之后，再把问题拆成：**播放概率** 和 **播放条件下的观看时长**，因为这两者的偏差来源完全不同。

## 一份高质量回答
排序分数定义为：`分数 = P(播放) × E[观看时长 | 已播放]`，也就是每个候选内容的**期望观看时长估计值**。
举两个例子说明为什么这个指标才是合理目标，而点击率CTR不是：
- 影片A：缩略图吸引人，播放概率P(play)=0.20，但是观众很快退出：条件期望观看时长=4分钟 → 期望观看时长 = 0.8分钟
- 影片B：播放概率P(play)=0.08，但是用户愿意持续看25分钟 → 期望观看时长 = 2.0分钟

CTR排序会把A排在前面，优先级高出2.5倍；而期望观看时长排序会把B排在前面，同样高出2.5倍。而B这类内容，才和业务关心的会话留存、长期留存正相关。
这个问题里所有“标题党陷阱”本质上就是这种反转：只看点击的单模型根本无法区分「赢了点击，输掉观看」的情况。
直接对**所有曝光样本**预测观看时长看起来很诱人，但其实是错的：绝大多数曝光不会产生播放行为，单一回归模型的大部分能力都会用来学习“要不要点击播放”这个零膨胀决策，而低估我们真正想要估计的「播放后的条件观看时长」。
双分支结构（通常是共享底层的多任务网络）可以让两个任务的标签各自保持纯净。

## 流程图说明
请求：用户 + 上下文 → 候选召回（召回约1万条）→ 特征拼接（用户、内容、上下文特征）
→ 分支1：头1 P(play) 播放概率
→ 分支2：头2 E[watch | play] 已播放条件下期望观看时长
→ 组合：分数 = P(play) × E[watch | play]
→ 排序 + 多样性调控
→ 数据回流库：曝光、播放、观看秒数、展示位置
训练环节：基于逆倾向加权（propensity-corrected）做纠偏训练

## 标签是最难的一环
有三类偏差会扭曲标签，一个靠谱的回答必须全部提到：

| 偏差类型 | 偏差来源 | 修正方案 |
| ---- | ---- | ---- |
| 选择偏差 | 你只能观测到用户选择播放的视频的观看时长；其余样本的标签不是随机缺失，是**非随机缺失** | 观看时长分支仅在播放样本上训练；单独建模P(play)；对观测到的播放样本做**播放逆倾向加权** |
| 位置偏差 | 放在第1位的内容，比放在第30位的同款内容更容易被点击、获得更多关注 | 基于位置做逆倾向加权；或者训练时拼接一个学习出来的位置偏置项，线上推理时把这个偏置项置0 |
| 生存偏差（留存偏差） | 提前退出很容易被误判成短观看；一部90分钟电影只看了5分钟，这是失败样本，不是“5分钟观看成功” | 标签定义为完播率，或者做上限截断、价值加权后的观看秒数，不用原始时长；把早期退出标记为强负样本 |

## 标签变换
观看秒数是极度长尾分布：少数连续刷剧的样本会拉高均值，L2损失会被这些极值主导。
处理方式：预测 `log1p(秒数)`；或者把完播率建模在[0,1]区间；或者按分位数分桶，当成有序分类任务。
默认常用方案：对数回归，配合校准后的指数逆变换还原时长；当尾部极端、我们主要目标是排序时，分位数分桶会更鲁棒。
对异常极值做截断（比如通宵自动播放的8小时时长样本），防止污染训练。

## 特征与标签
- 用户特征：长期、短期观看Embedding，题材偏好，最近观看时间/时段，设备信息
- 内容特征：内容Embedding，元信息，上线时长，历史完播率（这个特征效果很强，但容易泄露偏差，需要谨慎使用）
- 上下文特征：所在行/展示位置、周边推荐内容、会话状态

重点：**必须记录每一次曝光在服务时的位置**；没有记录的偏差，就无法做去偏。
冷启动新内容：没有交互历史，依赖内容Embedding和元信息；搭配探索策略（一小部分ε随机投放，或者汤普森采样投放），让它们能拿到无偏的曝光，而不是永远没有展示机会。

## 线下指标必须匹配两个任务分支
- P(播放)分支：AUC，更重要的是**校准度**（可靠性曲线、ECE期望校准误差），因为这个概率会直接乘进最终排序分数；校准出错会悄悄改变整个排序权重
- 播放后观看时长分支：在变换后的尺度上计算MAE/RMSE，同时做好逆变换后的校准

但真正能预判线上效果的指标是**排序质量**：NDCG，或者基于观看时长加权的排序指标，在隔离的测试会话上评估；最好搭配反事实估计器（IPS逆倾向评分，或者双重稳健估计）评估策略好坏，而不只是拟合历史日志数据。

## 线上评估才是最终裁决
做交错实验或者A/B测试，核心指标：人均价值观看时长、单会话播放数、次日/次周留存；
同时设置防护约束指标：总会话时长（避免单纯刷高单一指标）、退出率、内容库多样性/覆盖率、公平性校验（保证新内容、小众题材依然能拿到曝光）。

典型失败现象：线下MAE下降，但线上互动持平甚至变差——这就是你在带偏差的标签上训练、没有做纠偏的典型后果；这个差距本身就是这道题的核心考点。

## 反馈回路与失效模式
模型决定展示哪些内容，这些曝光又变成第二天的训练数据，回路会自我强化：热门内容拿到更多展位、更多播放、看起来效果越来越好。
应对手段：探索投放、倾向日志记录、定期按内容上新时长、热度分布审计曝光占比。

其他失效场景：
- 标题党缩略图：拉高播放概率，但是看完就退出（这就是为什么我们优化期望观看时长，而不是单纯点击）
- 自动播放虚增时长：标签做截断、价值加权
- 内容库更新后，Embedding过时失效

## 面试官接下来常追问的问题
- “线下MAE变好了，但是A/B实验里互动数据变差，是什么原因？”
大概率是你优化了带偏差的标签：模型更好地拟合了历史策略产生的播放日志。检查位置偏差、选择偏差的修正，检查校准；相信线上观看时长和留存，而不是线下误差。
- “为什么不直接预测点击？”
点击会鼓励标题党和自动播放刷量；一个内容可以拿到播放，但是毁掉整个用户会话。期望观看时长（价值观看时长）才和业务真实目标对齐，这就是观看时长分支存在的意义。
- “完全没有历史数据的新影片怎么处理？”
用内容Embedding+元信息做冷预测；分配探索流量预算，让它拿到无偏曝光，不能让热度先验把它彻底埋没。
- “历史完播率这个特征效果最好，有没有隐患？”
这个特征一部分取决于当前策略本来就给谁曝光，会泄露策略自带的偏差，而且内容更新后容易失效。可以用，但是持续监控；优先选用具备因果性、而不是自证预言式的特征。

## 常见错误
1. 在全部曝光样本上训练一个观看时长回归器，让“要不要播放”这个零膨胀决策淹没条件观看时长估计
2. 无视标签是非随机缺失，直接拿MAE评估，仿佛观测到的播放样本具备代表性
3. 不记录展示位置，之后又声称自己做了去偏
4. 优化原始时长，让自动播放、挂机8小时的样本主导目标，而不是做截断和价值化标签
5. 长尾数据不做变换，L2损失被刷剧极值样本绑架
6. 只用线下MAE宣告模型成功，不做线上A/B验证——这个问题最大的风险就来自训练和线上推理之间的标签鸿沟

## 核心要点总结
- 两段式建模：P(播放) × E[观看 | 已播放]；不要对全部曝光样本只用一个回归器
- 标签是非随机缺失：必须修正选择偏差和位置偏差（逆倾向加权IPW或者学习位置项），不然线下指标是假的
- 对长尾标签做变换（log或分位数分桶），截断自动播放极值，优先用完播价值而不是原始秒数
- 校准很重要；但最终判定标准，是线上价值观看时长、留存，搭配多样性、会话时长这类防护约束指标

高级候选人的标志：主动说出选择偏差这个关键点——你只用已经被观看的样本训练，标签非随机缺失；朴素回归学到的只是「用户本来就爱选的内容更容易被看完」。优秀的候选人会对长尾标签做变换、把点击和播放后观看拆开、用倾向加权/学习位置项去偏，并且坚持：观看时长预测好不好，最终要看线上排序效果。面试官会用这个问题测试你：**线下MAE下降、线上互动变差，你怎么理解**，看你能不能看懂训练和线上之间的标签鸿沟。
