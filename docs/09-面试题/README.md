## 怎么用

1. 先按题号自己口述一遍，再对照文内「高分参考答案 / 优质回答参考」
2. 图示与 Mermaid 流程图在文内对应小节；站点 Docsify 已支持 mermaid 代码块渲染
3. 追问表与常见误区用来做第二轮加压，不要只背定义
4. 标「正文待补」的题号先跳过，或用对应概念课自练口述结构
