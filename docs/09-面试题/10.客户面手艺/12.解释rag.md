# 用两分钟向我们的首席法务官解释RAG。她精明干练、事务繁忙，不懂技术。

评分依据两项大多数工程师从不练习的能力：类比的质量，以及懂得何时停止讲解。下面这份两分钟讲解脚本适合讲给法务高管，同时说明了需要避开的深度陷阱。




> 一句话摘要：选用她熟悉领域的类比（就像初级律师在合伙人撰写备忘录前调取卷宗），落脚到法务高管真正关心的重点——准确性、引用溯源、保密性；如实说明局限性，然后停止讲解。懂得适时收尾，才是答案本身。

---
## 该如何作答
这道题考察视角切换能力，也就是前沿部署工程师的一项技能：早上9点给首席法务官讲解同一套系统，上午10点又要讲给平台技术团队。面试官会针对两点打分：类比质量（是否贴合听者的专业背景，经得起追问？）；讲解深度的把控（你能否忍住不去讲解嵌入向量这类技术细节？）。
对于法务高管，最好的思路是选用法律行业本身的类比，并且关联她真正在意的事：准确性、引用溯源、保密性。两分钟的时长大约对应250个词，需要计时演练。

### 优秀作答示例
适配时长的讲解脚本：

“您能体会到其中差别吧：让一位能力出众的同事仅凭记忆回答问题，和让他**先调取相关卷宗**之后再作答，二者完全不一样。这就是RAG的核心思路。

大语言模型本身，就像这位只凭记忆作答的同事：学识广博、表达流畅，但它的知识来自训练阶段学到的通用内容。它从未看过我们的合同、判例、操作手册。如果问它我们的赔偿责任标准，它能流利作答，但答案来自通用案例模板，而不是我们自己的文件。这就是大家所担心的：自信却错误的回答。

RAG，检索增强生成，改变了这套工作流程。系统给出回答前，会先从我们自有文档库中检索相关原文段落，就像初级律师，在合伙人起草备忘录前，提前找出对应的卷宗。随后模型会收到指令：**仅依据这些检索到的段落作答，并且标注原文出处**。所以当它给出结论，例如我们主服务协议里的责任上限为12个月服务费时，回答会附带对应合同条款的引用，我们团队核验这份答案，就像核查初级律师的工作成果。

这件事对您而言，有三层意义。
第一：所有回答都基于我们自己的文档，而非互联网上通用的合同模板。
第二：每一条答案都可核验，附带原文引用，不是凭感觉得出的结论。
第三：我们的文档不会用于模型训练；仅在提问的瞬间调取查阅，并且有权限管控。就像图书馆：可以借阅资料，但不会留存副本。

但它也有做不到的地方：文档里没有的内容，它无法获知；它偶尔依然会误读原文段落。因此，任何对外输出的内容，我们都会安排律师复核。”

讲到这里就停下。沉默本身就是考验。如果她想了解更多，她会主动提问。

| 不要这么说 | 换成这样表述 |
| ---- | ---- |
| 嵌入、向量、余弦相似度 | “它能找到和你的问题相关的原文段落，哪怕段落用词和你的提问不一样” |
| 检索增强生成 | “它在回答问题前，先去查阅你的文档” |
| 幻觉 | “它有可能非常肯定地说出文档里不存在的内容” |
| 分块、Top-K、重排序 | “它只阅读少数最相关的页面，而不是通读全部文档库” |
| 溯源、引用 | “每一条回答都会标出对应的原文段落，您几秒内就能核对来源” |

对首席法务官来说，表格最后一行才是核心表达。她不需要了解检索底层原理；她需要确认，每一项结论都可以溯源到一份可打开查阅的原始文档，并且系统会选择回答“我不知道”，而不是编造内容。

“两分钟”是硬性时间限制，不是随口的比喻。提前做好字数规划，才能在现场不超时。舒适的口语语速大约每分钟150词，两分钟大约300词。上面这份脚本刻意控制在略少于300词，留出空隙方便她中途插话（她一定会提问）。光是开篇调取卷宗这个类比就大约60词，需要24秒，也就是四分之一的时间，此时还没有提到RAG这个名词。这样分配时间是合理的，因为这个类比才是她能记住的内容。
这种字数规划带来的约束，本质是做减法：任何讲解检索底层原理的句子，都会挤占类比、保密要点这些她真正关心内容的时间。考生栽在这道题里，几乎从来不是说得太少；而是在第三分钟还在讲解嵌入向量——这些内容根本不在时间预算内。所以“懂得何时停止讲解”，和类比本身同等重要，都会计入评分。

### 面试官接下来可能追问的问题
- 她提问：“那它就不会编造内容了是吗？”——考察你诚实有度的表达。
  回答：它依然有可能误读调取到的文档，这种情况相对少见，但引用溯源可以帮我们发现这类错误。我们的设计目标是**可核验**，而不是绝对无误。

- 她提问：“这会把我们的文档发送给AI厂商吗？”——需要掌握真实答案：文档保留在我方环境/租户内；检索发生在查询阶段，支持零数据留存方案。

- “现在换成平台工程师加入会议，同样这个问题。”——需要立刻切换视角：分块、混合检索、引用片段、评估数据集。顺畅切换表述层级，是录用的关键信号。

## 常见错误
- 讲解深度超标：一旦说出“向量”或者“嵌入”这类词，你就没能通过讲解深度把控的测试。
- 使用通用类比（例如“开卷考试”），而没有选用贴合法律行业的类比（初级律师调取卷宗）。贴合受众，才是重点。
- 回避局限性。单纯像推销产品一样介绍功能，无法体现恰当的坦诚。尤其在Harvey这类公司，获取律师的信任本身就是产品核心。
- 讲满四分钟。题干明确提示：对方精明干练、时间紧张。懂得控制讲解边界，才是本题的答案。

## 最后一段
懂得适时收尾，才是这道题真正的考验。有一个信号代表你通过了测试：**收尾时讲局限性，而不是讲能力有多强大**。
首席法务官会更信任这样的表达收尾：“它依然有可能误读原文段落，所以任何对外流出的内容，都要由律师复核”，而不是一味强调系统多么强大。这句坦诚的结束语，才能帮你争取到下一次沟通机会。
