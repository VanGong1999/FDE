# 02 从头到尾梳理Transformer架构，不用复杂数学


**一句话摘要：** 梳理五个阶段（分词/嵌入、位置编码+残差链路、注意力机制、前馈网络/混合专家、下一个token采样），牢记一个核心区分：注意力机制负责在token之间传递信息，前馈网络存储世界知识。

## 如何作答
这里最忌讳说得流利空泛。如果候选人把混合专家（MoE）解释成“更小、更廉价的模型”，还说模型的知识“存放在注意力权重里”。这两句话听起来好像是对的，但其实完全颠倒了，而面试官恰恰就在留意这类错误。
在开始讲解前先定好基调：你要讲的是架构骨架，不是推导反向传播。说明你要顺着的流程（文本如何变成输出），然后一步步讲解：token、嵌入、位置编码、注意力、前馈块、采样。面试官真正考察的，是你能不能在脑中完整把握整个流水线，以及你是否清楚哪一部分负责token之间的信息交互、哪一部分负责存储知识。大部分候选人会混淆这两者；能把二者清晰分开，就说明你真的读过模型内部原理。

## 优质回答
所有现代大模型都共享这五个阶段。

面试官重点关注的是框图里的两个模块：阶段5和6，它们之间虚线箭头代表重复堆叠的单层。它们上方的所有步骤是准备输入，下方的步骤是读取输出。

1. **分词与嵌入**。模型读取整数，而不是单词。分词器把文本切分为子词片段，给每一段映射一个固定ID；嵌入矩阵把每个ID转化为一个长向量。含义存在于几何空间中：相关的概念在这个高维空间里彼此靠近。

2. **位置编码与残差链路**。普通注意力没有词语顺序的概念。旋转位置编码（RoPE）通过将查询、键向量按照和位置相关的角度旋转，让模型可以追踪token之间的相对距离。残差链路是贯穿整个网络的加法通道：每一层都是**在原有token向量上叠加更新，而不是覆盖重写**，这样在很深的网络堆叠中，早期的信号得以保留。

3. **注意力，信息通信器**。这是token之间交换信息的地方。每个token生成一个查询（Query：“我在找什么”）、一个键（Key：“我对外展示什么，供其他token检索我”），以及一个值（Value：匹配成功后我附带传递的信息）。查询和键做点积来衡量匹配程度，softmax把这些分数转换成总和为1的权重，然后层对值向量做加权平均。

这些符号很抽象，直到你看它如何处理代词指代。举个句子：“The server crashed because it ran out of memory（服务器崩溃，因为内存耗尽）”。当模型处理“it”这个token时，它的查询本质是在问：“我是代词，谁是我的指代对象？”。“server”的键向外表明“单数名词，这个句子的主语”，二者的匹配度远高于“it”和“crashed”或者“because”的匹配。所以加权平均会大量取用“server”的值向量，于是“it”这个token离开这一层的时候，向量就带上了server的语义。网络中不存在任何一条写死的代词解析规则；这个行为是**涌现**出来的，因为注意力学到了这种查询-键的几何结构可以降低预测误差。所有令人惊叹的长距离行为（比如在变量定义3000个token之后还能使用这个变量、对话开头内容的回调），本质上都是更长距离下的同一套机制。

这些字母符号一直很抽象，直到你看它如何解析代词。以句子 *The server crashed because it ran out of memory.*（服务器崩溃，因为内存耗尽）为例。当模型处理“it”这个token时，该token的查询相当于在发问：“我是代词，我的指代对象是谁？”“server”的键对外宣称自己是“单数名词，本句主语”，二者匹配程度远高于“it”和“crashed”或“because”的匹配。于是加权平均主要取用“server”的值向量，“it”的向量在离开这一层时就带上了server的语义。网络中不存在任何代词解析的硬编码规则；该行为之所以涌现，是因为注意力学到这种查询-键几何结构能够降低预测误差。所有惊艳的长距离行为（在变量定义3000个token之后仍能调用它、回调对话开头内容）都是更长距离下的这套相同机制。

4. **前馈网络与混合专家MoE：记忆库**。注意力负责在token之间传递信息，而前馈网络（FFN）**独立处理每一个token**：把向量升维，施加非线性激活，再压缩回来。模型绝大部分存储的事实知识都在这里。注意力是token之间的对话；FFN是每个token可以查阅的知识库。参数规模数据也印证这点：标准Transformer层里，FFN的两个矩阵的参数量大约是注意力模块的两倍（升维到4倍宽度再压缩回来，大约需要8d²权重，而注意力是4d²），所以你下载模型时得到的大部分内容就是这个知识库。这是实测结论，不是比喻。Geva等人2021年的论文《Transformer Feed-Forward Layers Are Key-Value Memories》证明，前馈层的行为等价于键值存储器：每个键匹配训练文本中的模式，每个值把概率推向该模式后面出现的token；低层存储浅层模式，高层存储语义层面的模式。论文开篇的参数统计也说了：前馈层占据Transformer三分之二的参数。
这也是为什么MoE专门改造FFN：FFN是最大的模块，而且它是按token单独查表，因此可以做路由分配。很多前沿模型用混合专家扩展它：每一层有大量并行的FFN专家，一个路由模块把每个token分配给少数专家（比如8个里选2个），于是总参数量可以大幅增长，但每个token的计算量不会随之上涨。

5. **下一个token预测**。在最后一层，最终的向量会和反向嵌入矩阵相乘，为每一个可能的token生成一个logit分数；softmax把这些分数转换成概率分布。温度参数会先缩放logit：低温（0.2）让结果更尖锐，偏向确定性输出；高温（1.4）增加多样性；top-k和top-p用来筛选候选池。这三个旋钮基本决定了模型表现出来的“性格”。
我们采样出一个token，追加到提示词后面；KV缓存保存过去所有的键和值，避免重复计算，然后循环重复这个过程。

### 面试官接下来可能追问的问题
- **“事实到底存在哪里？”** 大部分存在FFN/MoE权重里。注意力负责路由信息；它不存储世界知识。
- **“为什么要用MoE？”** 它把总参数量和单token计算量解耦：路由到8个专家中的2个，你就能获得超大模型的能力，而推理开销只占一小部分。
- **“KV缓存的开销是什么？”** 内存占用随【序列长度 × 层数 × 头数】线性增长。这就是长上下文推理成本很高的原因，也是为什么批大小和上下文长度会争抢同一块GPU显存。
- **“为什么选RoPE，而不是可学习位置编码？”** 它支持相对位置，外推到比训练时更长的序列时效果更干净稳定。

### 听起来正确，但和模型内部原理相悖的说法
|人们常脱口而出的说法|错在哪|应该这样回答|
| ---- | ---- | ---- |
|“事实存在注意力里面”|注意力只是在token之间做加权平均；它传递信息，不存储信息|**注意力负责路由，FFN负责存储**|
|“MoE是更小的模型”|总参数量不变甚至更大；只是每个token只会激活一部分专家|**同等能力，每个token激活更少参数**|
|“它只是预测下一个token”|这句话没错，但没有说明任何机制，无法证明你的理解|把五个阶段梳理一遍，再说明知识存放位置|
|“温度改变模型本身”|它只是采样前缩放logit；权重完全没有变化|**它只是从固定分布里重塑采样结果**|

### 常见错误
- 只停留在“它只是预测下一个token”。这句话本身没错，但没有描述机制，面试官会认为你只是刷过论坛帖子，没有读模型资料。
- 认为事实知识存在注意力里。注意力是路由；FFN才是存储器。
- 只会背诵softmax和点积公式，不理解Q、K、V的实际作用。
- 误以为温度、top-k、top-p会修改模型。它们只是重塑采样的分布；权重永远不变。

## 核心要点
- **注意力负责路由，FFN负责存储**：说出这句话，就能证明你读懂了模型内部原理。
- MoE保持单token计算量不变，同时通过每个token只激活少数专家，提升模型总容量。
- 采样参数（温度、top-k、top-p）重塑固定分布；它们永远不会改动权重。
- 尽早说出**“注意力负责路由，FFN负责存储”**；如果被追问，就补充三分之二参数分布这个知识点。这两点的差别，就是真正读过模型文档，和只看过新闻标题的人的分水岭。



## 面试要点拆解
能拿下这轮面试的金句是：**注意力做信息路由，前馈网络存储知识（attention routes, the FFN stores）**。只要把这句话讲到位，面试官往往会跳过剩下的架构问答题。

很多实力不错的候选人会踩一个陷阱：把MoE（混合专家模型）解释成“一个更小的模型”。实际上MoE模型总参数量不变，只是每个token只会激活其中一小部分参数。如果把这两者混为一谈，就会暴露你只看了新闻标题，并没有理解路由机制。

针对“前馈网络存储知识”这一说法值得补充一个保留意见：这是主流直观理解，但现实比这句简短概括要模糊。注意力头的value向量同样承载事实关联；大量存储的知识分散存放在注意力层与前馈网络二者之中，可解释性研究至今仍在梳理它的分布规律。这句话之所以是绝佳面试答案，恰恰因为它是简洁抽象总结，而非严谨精确的科学论断。

### 1. attention routes, the FFN stores
- **Attention（注意力层）：负责路由、关联、检索信息**
注意力机制完成token之间的关联匹配，决定该调取哪些信息，做“信息路由调度”，**不长期储存知识**。
- **FFN（Feed‑Forward Network，前馈网络）：存储事实知识**
经过训练，大量事实、常识知识编码保存在FFN的权重当中。

> ⚠️重要限定：这是**面试抽象口诀**，不是严格学术结论。
> 真实模型中注意力的value向量也会携带事实信息，知识是跨层分布式存储，并没有100%完全割裂。面试先说这句金句，再补充这个 caveat（保留意见），直接拉开和普通候选人差距。

### 2. MoE（Mixture‑of‑Experts，混合专家模型）高频坑
❌错误：MoE = 更小的模型
✅正确：
MoE**总参数量很大，甚至比同效果稠密模型更大**；每一个token经过路由（router），只激活一部分专家参数参与计算。
- 总参数规模不变，**每次激活计算的参数变少**，带来推理速度收益。
- 混淆“总参数量”和“单token激活参数量”是高频扣分点，代表只看科普标题，不懂router路由逻辑。
