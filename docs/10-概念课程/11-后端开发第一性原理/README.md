# 11 · 后端开发第一性原理

本目录把「后端开发规则」从第一性原理讲清楚：不绑死某一语言或框架，先建立**跨技术栈可迁移的心智模型**，再谈 Express / Spring / FastAPI / Rails 怎么写。

适合：**不会后端、或只会在某一框架里写 CRUD、却看不懂生产级后端在干什么**的人。读完应能独立判断：请求从哪进来、在哪校验、谁管业务、数据怎么存、错了怎么暴露、怎么扩、怎么守安全、怎么上线。

> 来源：`待整理的后端开发课程/` 视频字幕（后端第一性原理系列）。**01–31 课均已整理为完整中文笔记**（约 7900 行）。
