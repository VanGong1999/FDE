# 02 · 检索与 Agent 概念课

本目录是面向 FDE（Forward Deployed Engineer）的**原创中文概念课**：把检索增强、向量与混合搜索、Agent/工具/护栏、以及若干互操作与支付相关协议，写成可面试、可进场讲解、可对照本库落地文的短文。

> 写作原则：一句话直觉 → 讲解 → 工作示例 → 面试取舍 → 现场用法 → 本库链接 → 参考来源。不照搬外部付费站正文。
