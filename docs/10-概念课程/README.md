# 概念课程总索引

本目录是 FDE 备面与现场共用的 **原创中文概念课**：按轨道建立直觉、工作示例与取舍，再回到面试题练口述。

## 与 `docs/09-面试题` 的关系

| | 概念课（本目录） | 面试题（`docs/09-面试题`） |
|--|------------------|---------------------------|
| 目标 | 建立直觉、决策框架、现场用法 | 练答题结构与口述节奏 |
| 读法 | 先懂「为什么 / 何时选」 | 再练「60 秒怎么说」 |
| 产出 | 可进客户对话的概念卡片 | 可进面试的标准答法 |

**一句话：概念课学直觉，面试题练口述。** 两轨主题大量重叠（窗口、RAG、限流、编码题等）——请以本课打底，再到 `09-面试题` 对应题号开口练。行为与客户场景另见 `docs/04-面试通关`（客户模拟、Decomposition、STAR）。

## 建议学习路径（速览）

1. **生成式底座**：01 →（需要检索时）02  
2. **能不能上线**：03 评测 → 04 生产 → 05 MLOps  
3. **跑得动、算得过账**：06 Serving ↔ 04 成本/限流  
4. **数据进得来**：07；**别把企业搞炸**：08  
5. **编码轮与现场工程**：09  
6. **客户现场与行为面**：10（配合 `docs/02-交付方法论`）  
7. **不会后端 / 补后端规则**：11（HTTP → 分层 → DB → 队列 → 安全 → 性能）

## 写作约定

各轨道篇目遵循七段结构：**一句话直觉 → 讲解 → 工作示例 → 面试取舍 → 现场用法 → 本库链接 → 参考来源**。原创中文，强调 FDE 取舍，不照搬外部付费站正文。
