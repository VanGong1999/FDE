## 5. 建议选修顺序

1. SSO/权限（几乎所有 AI 交付）  
2. 变更管理（几乎所有上线）  
3. 数据工程基石 → 目标平台（Snowflake/Databricks 或 GCP）  
4. 网络白话 / 气隙（按客户约束）  
5. 产品化（有一个成功试点后）
