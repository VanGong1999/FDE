# 零基础编程补课地图

给编程较弱、希望最终走上 FDE 路径的读者。目标是 **2–4 周达到能并入转岗 Week 2**，不是成为算法竞赛选手。

完整路径说明见 [学习路径-零基础](../00-导读/学习路径-零基础.md)。

---

## 1. 学习原则

1. 每周必须有**可运行产物**  
2. 只深挖一条语言：建议 **Python**  
3. 先 API 与脚本，再框架  
4. 用 Git 管理一切  

---

## 2. 四周大纲

### 第 1 周 — Python 与环境

- 变量、函数、列表/字典、文件读写、虚拟环境  
- **产物**：读取 CSV 并打印汇总  

### 第 2 周 — HTTP API 与密钥

- `requests` 或 `httpx`；状态码；JSON  
- 环境变量存密钥；`.gitignore`  
- **产物**：调用任一 LLM API，打印回复（遵守服务商条款与费用）  

### 第 3 周 — Git 与小项目结构

- clone/commit/branch；写 README  
- 把脚本拆成 `main.py` + 配置  
- **产物**：GitHub/本地仓库，他人可按 README 运行（无密钥）  

### 第 4 周 — 最小「知识问答」

- 读取本地 `.md`/`.txt`，简单关键词检索 + LLM 总结（或先手工粘贴上下文）  
- 写清局限（无权限、无评测）  
- **产物**：Demo + 半页「若要生产还缺什么」（对照 [生产化清单](../03-AI落地/生产化清单.md) 扫一眼）
