## 精华摘要

OWASP 为 LLM 应用整理了优先风险清单（版本迭代替换具体条目编号时请回原文核对）。对 FDE，其价值不是背编号，而是：**在方案设计与门禁里主动点名风险与控制**，并把控制落到检索层、工具网关、输出过滤与运营熔断——而不是「模型自己注意安全」。

## 重点内容

### 常见风险类别（意译归并，细节以官方当前版为准）

| 风险主题 | 现场含义 | 工程控制方向 |
|----------|----------|--------------|
| 提示注入 | 用户或文档诱导忽略策略 | 指令与证据隔离；工具层不执行文档指令 |
| 敏感信息泄漏 | PII/密钥进日志或出站 | 脱敏、保留期、DLp、私有链路 |
| 供应链 | 模型/插件/模板来源 | 供应商评审、锁定版本 |
| 不安全输出处理 | 输出当命令执行 | 永远校验；勿直接 eval |
| 权限过度 | 服务账号万能 | 最小权限、用户身份代理 |
| 过度自主/代理滥用 | 不可逆动作 | 工具分级、HITL、步数预算 |
| 数据投毒/腐蚀 | 污染知识库或反馈 | 来源治理、审核入库 |
| 幻觉被当事实 | 无证据断言 | 强制引用、拒答、下游校验 |
| DoS / 成本爆炸 | 超长上下文、循环调用 | 限额、超时、熔断 |
| 越狱与滥用 | 绕过策略 | 多层护栏 + 监控 |

### 设计评审时的三问

1. 攻击者最想骗系统做什么？  
2. 该动作是否在工具层就被物理不可能？  
3. 出事谁能在多久内发现并回滚？
