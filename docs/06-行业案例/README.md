# 06 行业案例

可复用的 **行业/场景案例**（合成教学向）：背景 → Discover → Design → Deploy → Review。  
写法对齐 [_案例模板.md](./_案例模板.md)。技术细节交叉引用 `docs/02`/`docs/03`。

## 案例列表

| # | 案例 | 主模式 | 适合练习 |
|---|------|--------|----------|
| 01 | [客服坐席助手](./01-客服坐席助手.md) | RAG + 确认模式 | 推回全自动、采纳率指标 |
| 02 | [企业知识库问答](./02-企业知识库问答.md) | 权限感知 RAG | ACL、拒答、引用 |
| 03 | [内部研发 Copilot](./03-内部研发Copilot.md) | 代码库 RAG | 保密、路径引用 |
| 04 | [合同单据审核 HITL](./04-合同单据审核HITL.md) | 抽取 + HITL | 漏检量规、责任叙事 |
| 05 | [流程型工单 Agent](./05-流程型工单Agent.md) | 工作流 + 工具分级 | 反无限 Agent |
| 06 | [限域数据分析助手](./06-限域数据分析助手.md) | 语义层 + Text-to-SQL | 口径与成本治理 |

## 如何使用

1. 先读案例的 Discover/硬点，自己画方案，再对照 Design  
2. 用案例做 [Decomposition](../04-面试通关/Decomposition拆解面.md) 口述练习  
3. 把「可操作清单」搬到你的模拟项目
