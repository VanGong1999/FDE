# 案例：合同 / 单据审核（HITL）

> 状态：可发布  
> 类型：合成教学案例  
> 主模式：文档理解 + 规则/模板对照 + 强制人机回环  

## 1. 背景

- **组织**：制造/零售企业法务 + 采购，供应商合同量大  
- **痛点**：初审积压；漏看高风险条款；新人标准不一  
- **错误代价**：高（赔偿责任、排他、自动续约等）  

## 2. Discover

- **用户**：初审律师/法务专员；业务催进度；法务负责人要质量  
- **指标**：初审人均时长、高风险漏检率、返工率  
- **约束**：合同不出域；需完整审计；模型建议不能替代签字责任  
- **问题陈述**：法务在初审时需要系统标出与模板/政策不符的高风险点并引用原文，缩短初读时间且不增加漏检  
- **非目标**：不做自动对外改写发送；不做商务谈判策略建议  
- **硬点**：高风险类目定义与标注；PDF/扫描件质量；责任边界沟通  

## 3. Design

- **主模式**：解析 → 条款切片 → 对照模板/禁限清单 → 模型辅助归类 → **律师确认** → 写回 CLM/文档批注  
- **架构**：私有链路或专有环境；证据高亮；每条建议绑定原文偏移  
- **试点**：NDA + 保密 + 赔偿责任三类 × 1 个法务小组 × 6 周  
- **Eval**：专家标注 200 段；优化漏检（召回）优先于误报；律师修正率作为采用指标  

## 4. Deploy

- **HITL**：所有「高风险」必须人工确认才进入下一流程节点  
- **培训**：工具是「第二双眼睛」不是「自动批准」  
- **审计**：谁看了哪份合同、模型建议、人工最终结论全记录  
- **事故**：若漏检进入签署 → 立即停该类自动提示 → 根因进黄金集  

## 5. Review

- **结果**：目标条款类初审时长下降约 35%；漏检在测试集可控；扫描件仍是瓶颈  
- **学习**：责任叙事比模型分数更能决定采用  
- **可复用**：条款类型切片、漏检优先量规、强制 HITL  
- **下一步**：扩展知识产权条款；上 OCR 质量门禁  

## 6. 可操作清单

- [ ] 书面责任矩阵：模型建议 ≠ 法律意见  
- [ ] 先标 1–2 类高风险再谈「全合同」  
- [ ] 召回优先的量规与业务共创  
- [ ] 原文高亮为必选 UX  
- [ ] 出域/私有化路径早定
